# 视频下载器

批量下载无水印短视频：AI 自动过滤带水印的内容，图形界面操作，Windows 免安装 exe。

## 版本

- **V1.0（当前）**：抖音视频下载 — 合集/散片批量下载、AI 水印过滤、图形界面、便携 exe
- V1.1（规划）：接入快手
- V1.2（规划）：接入 B站、小红书

## 主要功能

- 📺 **合集下载**：搜索短剧合集，整部按集归档
- 🎬 **散片下载**：按关键词搜索单条视频，按时间分桶归档
- 🤖 **AI 水印过滤**：自动识别并隔离带作者水印的视频
- 🖥️ **图形界面**：目录浏览、任务进度、视频预览、条件筛选
- 📦 **免安装运行**：打包为 Windows 便携 exe，解压即用

## 快速开始

**普通用户**：从 [Releases](https://github.com/lkhxxx123/video-dl/releases/tag/v1) 下载 `视频下载器.zip` → 解压 → 双击 `视频下载器.exe` → AI 配置填 Key → 扫码登录 → 执行。

**开发者**：

```cmd
pip install -r requirements.txt
playwright install chromium
python run.py ui
```

## 命令

| 命令 | 说明 |
|---|---|
| `run.py ui` | 图形界面 |
| `run.py jx "关键词" [参数]` | 合集下载 |
| `run.py clips "关键词" [参数]` | 散片下载 |
| `run.py login` / `doctor` / `selftest` | 登录 / 环境自检 / 自测 |
| `run.py wm <目录> --rejudge` | 水印重判 |
| `run.py dl "分享口令"` | 单条下载 |

## 常见问题

| 问题 | 处理 |
|---|---|
| 提示未登录 | 点「扫码登录」，过期时任务会自动弹浏览器等待补登 |
| 水印误判 | `run.py wm <目录> --rejudge` 平反；被隔离视频在 `疑似水印\` |
| exe 报错/闪退 | 看 `logs\运行日志.txt`；SmartScreen 警告点"仍要运行" |
| 中断后继续 | 重跑同一命令/任务自动续；删掉文件即重置状态 |
